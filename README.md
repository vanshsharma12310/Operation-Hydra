# Screenshots

Place tool-output screenshots here, named to match the evidence they
support, e.g.:

- `mxtoolbox-spf-nimbusfinserv.png`
- `virustotal-hash-lookup.png`
- `abuseipdb-203.0.113.44.png`
- `whois-nimbus-secure-verify.png`
- `blockchain-explorer-wallet-trace.png`

When you run the real tools (MXToolbox, VirusTotal, AbuseIPDB, a block
explorer) against the simulated indicators in `evidence/`, save the
resulting screenshots here and reference them in the final report.

This directory is checked for existence (not content) by the CI workflow
in `.github/workflows/ci.yml`.
